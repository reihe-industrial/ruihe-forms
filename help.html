使用說明

登入所有人

從「首頁」登入，有兩種方式：

  • 使用 Google 帳戶登入：管理員在「人員管理」幫你設定好 Gmail 後就能用，按一下就登入。
  • 使用通關碼登入：選自己的名字，輸入通關碼。忘記通關碼請找管理員。

同一個瀏覽器分頁登入一次，其他功能頁都不用再登入。30 分鐘沒有動作會自動登出。

在共用電腦上用完，一定要按右上角的「登出」。

首頁所有人

登入後的首頁由上而下分成三個區塊：

  • 待辦提醒：數字卡片，點了下面才展開清單。紅色、橘色是要處理的，灰色的 0 表示沒有。
    • 客需：今天要聯絡、超過 30 天沒追蹤
    • 物件：合約 30 天內到期
    • 新物件符合你的客需（最近 7 天）
  • 公告：公司的通知，紅色「重要」的放在最上面。
  • 行事曆：
    • 綠色是公司活動（秘書、管理員新增），大家都看得到。
    • 橘色是我的行程：按「＋ 我的行程」，點選行程類型、日期、時間、預期效益就能存；對象和地點會列出你最近用過的，點一下就帶入。只有自己和秘書看得到，其他業務看不到。
    • 點日期看當天的內容；點一筆可以修改或刪除自己的行程。

主管、秘書、管理員可以切換「我的／全公司」。

新增物件所有人

  1. 選上面的類型：廠房／土地／房屋。
  2. 從上往下填。紅色星號 * 是必填；有些欄位要看前面的選擇才必填（例如房屋的管理費選「有」，管理費用和繳費方式就要填）。
  3. 電腦版左邊的目錄顯示每一段還缺幾項，點了直接跳過去。
  4. 最下面的送出列會顯示「還有 N 項必填沒填」，按「跳到第一項」可以直接跳到沒填的欄位。
  5. 照片：可以一次選好幾張。權狀、謄本、使用執照、合約這類要看清楚小字的，請在檔案旁勾「保留原圖」。
  6. 按「送出」，看到成功訊息就完成了。
填到一半離開，回來時會問要不要繼續使用草稿。

修改物件／客需／物件配對所有人

登入後從選單進入，分成「物件」「客需」兩個分頁，只會列出你負責的（秘書、管理員看全部）。

修改

按「修改」打開，改完按最下面的「儲存」。如果有人在試算表直接改過，上方會列出最新的值。

刪除輸入錯誤的物件或客需

只是不賣了的物件，請把「案件狀態」改成已下架，不要刪除。真的輸入錯誤（例如重複輸入）才刪：

  • 業務、主管：按「申請刪除」，填原因送出。清單上會顯示「刪除申請中」，秘書或管理員看過同意後才會刪除。
  • 秘書、管理員：按「刪除」，填原因就直接刪除。

刪除後所有地方都會移除（包括這件的契變紀錄），資料會先備份，刪錯可以找管理員救回。

配對

每一筆旁邊的「配對（N）」，N 是符合的件數：

  • 物件 → 看符合的客需（有興趣請找負責業務）。
  • 客需 → 看符合的物件。

配對會比對：類型、買／租、區域、坪數、預算。預設只列同一區的，勾「也顯示鄰近區域」會多列附近的。

契變

  1. 打開物件後，按上方的「契變」。
  2. 填契變書編號、契變日期，勾變更項目（到期日、價格、委託內容、委託人、其他），再填新的內容。
  3. 按「儲存契變」，到期日、價格、委託人會更新成新的內容。
  4. 契變書紙本交給秘書。

下方的「契變紀錄」會保留每一次契變，最新的標「最新」。

填錯或測試用的可以按「刪除」（自己填的才能刪；秘書、管理員都可以刪）。刪除最新的一筆時可以勾「同時把到期日、總價、委託人改回契變前的值」。

新增客需、客需追蹤所有人

必填：負責業務、填表日期、資訊來源、物件類型、需求類型、目標區域，以及依物件類型：

  • 廠房：產業類別、廠房面積
  • 土地：土地面積、需求土地種類
  • 房屋：房屋面積

面積和預算可以寫一個數字或範圍（例如 200～300）。坪數、預算有填，配對才會準。

追蹤紀錄

到「修改物件／客需／物件配對」→「客需」→「修改／追蹤」，在上方新增追蹤紀錄，填下次聯絡日期，首頁就會提醒你。成交或不需要了，記得把客需結案。

物件簡表、產生 DM所有人

全公司銷售中的物件（含住商物件），可以用類型、租售、區域、坪數、總價、業務篩選。每一列按「更多」看其他欄位。

產生 DM

  1. 按那一件的「產生 DM」。
  2. 「下載圖片」：直式圖片，適合傳 LINE。
  3. 「A4 版面（存成 PDF）」：跳出列印視窗，目的地選「另存為 PDF」。
  4. 「Word 檔（可編輯）」：下載表格式的物件說明（.docx），服務人員、聯絡電話、仲介服務費和其他內容都可以在 Word 裡改。

DM 上的聯絡業務是產生 DM 的人，電話來自人員管理的設定；公司資訊和經紀人資訊會自動帶入。

客需簡表所有人

全公司的客戶需求，可以篩選類型、區域、業務。有符合的客戶，請找負責業務。

物件地圖所有人

銷售中的物件放在地圖上，點標記看簡介。可以篩選類型、租售、業務、建物坪數、總價、土地坪數。

調謄本所有人

  1. 勾負責業務。
  2. 選縣市、鄉鎮市區、段名，填地號或建號，勾謄本種類。有填建號的話，地址必填。
  3. 好幾個段可以按「＋ 新增一筆地段」一次申請。
  4. 按「送出申請」。90 天內申請過同一筆會提醒你。

主管主管

  • 首頁可以切換「全組」，看組員的待辦。
  • 「物件總表」只能看，不能改。
  • 只能修改自己負責的物件和客需。

秘書專區秘書、管理員

  • 申調謄本：改狀態、內部備註、費用，按「儲存變更」。可以勾好幾筆一起改狀態。
  • 人員管理：在職、身分、組別、電話（DM 會用到）、通關碼、Gmail。秘書改身分或組別要送申請，由管理員同意。
  • 契變：業務填的契變，收到契變書勾「已收件」；填錯的可以刪除。
  • 刪除申請：業務申請刪除的物件、客需，看過後按「同意刪除」或「不同意」。首頁也會提醒待審核的件數。
  • 公告：首頁的公告，可以設重要（紅色置頂）和顯示期間。
  • 異動紀錄：誰在什麼時候改了哪一筆。
  • 首頁的行事曆可以新增公司活動，也看得到所有業務的行程。
  • 物件總表可以直接改格子：「修改資料」→ 點格子改 → 「儲存變更」。

管理員管理員

  • 系統設定：提醒天數、自動登出時間、配對的坪數和預算差距、鄰近區域公里數等，不用改程式。最下面有「讀取速度測試」。
  • 系統狀態：排程最後一次有沒有成功、背景處理有沒有卡住、座標待確認幾筆。
  • 權限對照：每種身分可以做什麼。
  • 新同仁要用 Google 登入：在人員管理填 Gmail 就好。
